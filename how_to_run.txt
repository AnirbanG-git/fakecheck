🧮 1. interpreting the metrics
metric	value	what it means
accuracy	0.9551 → 95.5 %	proportion of all news items (real + fake) correctly classified. out of every 100 articles, about 95 are labeled correctly.
precision	0.947 → 94.7 %	among the items predicted as fake, this is the fraction that truly are fake.
high precision ⇒ few false alarms (rarely tags real news as fake).
recall	0.967 → 96.7 %	among all the actually fake items, this is the fraction your model caught.
high recall ⇒ few missed fakes.
f1	0.9568 ≈ 95.7 %	harmonic mean of precision and recall.
balances both; a perfect classifier = 1.0.
auroc	0.990 ≈ 99 %	“Area Under the Receiver Operating Characteristic Curve.” measures how well the model ranks real vs fake regardless of threshold.
1.0 = perfect separation, 0.5 = random guessing.
0.99 means your TF-IDF + LR baseline distinguishes the classes almost perfectly.
quick read:

precision ≈ 95 %, recall ≈ 97 % → balanced.

AUROC ≈ 0.99 → your feature space (TF-IDF bigrams) is already very discriminative on WELFake.

F1 ≈ 0.956 → this baseline is strong; later models must justify extra complexity with explainability and generalization rather than raw accuracy.

Week 6 — Experimental Design (WELFake)
----

What we’ll compare

Baseline-LR (internal only): TF-IDF + LR verifier (your artifacts/verifier_lr/*.joblib) using only internal evidence.

Baseline-BERT (internal only): your artifacts/verifier_bert/ using only internal evidence.

Agentic-BERT (internal + external): your end-to-end agent (BM25+E5+cache) + BERT verifier + explainer.

Same test split (from reports/verifier_dataset.jsonl) for all; same label space; identical metrics.

Metrics we’ll report

Accuracy, Precision, Recall, F1, AUROC

Retrieval Coverage: % claims with ≥1 internal hit; % with ≥1 external snippet (agentic only)

Confusion Matrix

Calibration snapshot (optional: ECE)

(Optional) explanation length/readability as a proxy

Statistical test

McNemar’s test (baseline vs agentic on test split) to show if accuracy differences are significant.
